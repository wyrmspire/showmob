# Firewall rules and NAT: fifth scoped security page

Written by Instinct. The planned sheet precedes representation, draft, critique, and the preview artifact under `runs/local-security-lab/pages/local-security-lab-firewalls-explained/` and `app/src/content/local-security-lab-firewalls-explained.json`. The core distinction is translation versus permission. A stateful reply, an unsolicited IPv4 packet without a mapping, a forwarded IPv4 packet and a new IPv6 packet have different questions; none proves end-to-end reach from a router setting alone. The page is read-only and does not recommend opening or probing a service.

RFC 4864 and RFC 6092 ground the IPv6/stateful-filter distinction; FTC home-network guidance grounds the router and UPnP discussion. Local pixels were inspected at 390px and 1280px. This is same-author critique, not independent validation. After inventory PR #112 landed, this page was rebased onto main.
